# count 

This code uses the count() method to find how many times the value in the appears in the tuple. for example:

my_tuple = (1, 2, 2, 2, 3, 2, 4)

count_2 = my_tuple.count(2)

print(count_2)  # Output: 3

# index

This code uses the index() method to find the first occurrence of the value in the tuple. for example: 

my_tuple = (10, 20, 30, 40)

position = my_tuple.index(40)

print(position)  # Output: 3
